# 🎯 Definition of Done

## Implementation
- [ ] Behavior matches issue acceptance criteria.
- [ ] Invalid input cannot corrupt game state.
- [ ] No unrelated generated files or dependency directories are included.
- [ ] UI and rules remain separated where practical.

## Verification
- [ ] Relevant unit tests added or updated.
- [ ] Relevant component/integration tests added or updated.
- [ ] Production build run and result recorded.
- [ ] Manual QA completed for visible behavior.
- [ ] Accessibility impact reviewed.

## Documentation
- [ ] README updated if user-facing behavior changed.
- [ ] Rules updated if mechanics changed.
- [ ] Architecture diagrams updated if module boundaries changed.
- [ ] Known limitations and migration notes recorded.

## Delivery
- [ ] PR describes scope and risks.
- [ ] Screenshots or recording attached for visual changes.
- [ ] No secrets or personal data committed.
