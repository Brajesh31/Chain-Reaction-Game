# 🎮 Manual Playtest Script

## Session setup
Record browser/device, commit, viewport, player count, board preset and session date. Avoid collecting player names or personal data.

## Tasks
1. Start from the title screen without help.
2. Choose a three-player match and an 8×8 board.
3. Explain which cells can be selected.
4. Make a move into an empty cell.
5. Attempt to select an opponent-owned cell.
6. Create a controlled corner burst.
7. Describe what changed during the cascade.
8. Switch theme without restarting.
9. Open and close the rules panel.
10. Complete a match or explain what information is missing to identify a winner.

## Observe
Where did the player hesitate? Was the active player clear? Could they predict affected neighbors? Were invalid moves understandable? Did motion obscure state? Could every action be completed by keyboard?

## Debrief
Capture task completion, friction, accessibility barriers and prioritized actions. Do not turn one qualitative session into unsupported usage statistics.
