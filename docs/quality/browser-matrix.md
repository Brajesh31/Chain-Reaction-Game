# 🧪 Browser and Device Test Matrix

| Platform | Browser | Viewports | Priority |
|---|---|---|---|
| Windows/macOS/Linux | Chrome | Desktop and responsive | Required |
| Windows/macOS/Linux | Firefox | Desktop | Required |
| macOS/iOS | Safari | Desktop/mobile | Required |
| Windows | Edge | Desktop | Recommended |
| Android | Chrome | Portrait/landscape | Required |
| iOS | Safari | Portrait/landscape | Required |

Test title/setup navigation, player/grid options, valid and invalid moves, cascades, theme, fullscreen, rules panel, reduced motion and keyboard focus.

Record version, OS, device, viewport, outcome and issue. Untested means not tested, not implicitly supported.
