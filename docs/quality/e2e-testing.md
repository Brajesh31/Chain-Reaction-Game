# 🧭 End-to-End Testing

No Playwright, Cypress or browser automation framework is currently configured. CI uses Jest/React Testing Library plus a production build.

Recommended browser journeys: title to setup, two/three/four player configuration, legal/illegal moves, corner/edge/interior burst, multi-wave cascade, reset after a match and during cascade, winner flow, keyboard-only play, reduced-motion and mobile viewport.

Choose one browser runner only when it can be maintained reliably. Until then these journeys are manual QA, not automated coverage.
