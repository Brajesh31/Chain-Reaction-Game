# 📦 External Dependencies

## Runtime packages
| Package | Role |
|---|---|
| react / react-dom | UI rendering |
| styled-components | Component styles and keyframes |
| framer-motion | Motion in the visual experience |
| web-vitals | Optional metric callbacks; no analytics endpoint is configured |

## Build/test packages
| Package | Role |
|---|---|
| react-scripts | CRA development, Jest integration and production build |
| @testing-library/react | Component rendering/interactions in tests |
| @testing-library/dom | DOM helpers used by testing libraries |
| @testing-library/jest-dom | DOM assertions |
| jest | Test runner |

Exact versions and transitive dependencies are in package.json and package-lock.json. This is a purpose summary, not the complete dependency graph. Check maintenance, license, advisories, peer compatibility and transitive changes before updating.
