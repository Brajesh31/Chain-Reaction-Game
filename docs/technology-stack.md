# 🧰 Technology Stack

| Layer | Technology | Role |
|---|---|---|
| UI | React 19 | Component-driven interface |
| DOM renderer | React DOM 19 | Browser rendering |
| Build/dev/test | Create React App 5 / react-scripts 5.0.1 | Start, tests and production bundle |
| Styling | styled-components 6 | Component styles and keyframes |
| Motion | Framer Motion 12 | Motion in visual experience |
| Optional metrics | web-vitals 2 | Web Vitals callbacks; no analytics endpoint configured |
| Tests | Jest 27 and React Testing Library | Unit/component verification |
| CI runtime | Node.js 20 and npm | Install, tests and build |
| Repository automation | GitHub Actions, Dependabot, CodeQL | Validation and security automation |

No server framework, API client, database driver, authentication provider, cloud storage SDK or socket client is required by the current local game. Update package.json and package-lock.json together using npm and justify every new dependency.
