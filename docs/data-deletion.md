# 🗑️ Data Deletion

There is no account or persistent match database to delete. Reset creates a fresh local match state. Reloading or closing the page discards the current React-memory match.

Reset is not an account-deletion mechanism and does not erase browser history, device backups, hosting access logs or browser extensions.

When persistent data is introduced, provide a user-visible deletion path, authorization, backup-retention behavior, audit evidence and support escalation.
