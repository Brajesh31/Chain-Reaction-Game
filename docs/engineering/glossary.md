# 📖 Project Glossary

| Term | Meaning |
|---|---|
| Active player | Player allowed to make the next legal move |
| Board | Rectangular matrix of game cells |
| Burst | Cell reaching critical mass and distributing orbs |
| Cascade | One move producing successive bursts |
| Cell | Board position with owner and orb count |
| Critical mass | Number of in-bounds orthogonal neighbors |
| Edge cell | Non-corner cell on the outer boundary |
| Hot-seat | Players sharing one device and passing turns |
| Owner | Player identifier controlling a non-empty cell |
| Orthogonal neighbor | Cell directly up, down, left or right |
| Turn | One player's opportunity to make a legal move |
| Unstable cell | Cell whose count has reached critical mass |
| Winner | Player remaining under the implemented endgame rule |

Keep terminology consistent with source and rules. Do not describe local hot-seat play as online multiplayer.
