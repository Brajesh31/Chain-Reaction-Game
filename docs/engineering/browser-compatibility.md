# 🌐 Browser Compatibility

The package declares Browserslist targets for production and recent Chrome/Firefox/Safari during development. These declarations are not proof of tested compatibility.

| Browser family | Desktop | Mobile |
|---|---|---|
| Chrome / Chromium | Required | Required on Android |
| Firefox | Required | Smoke test |
| Safari | Required | Required on iOS |
| Edge | Recommended | N/A |

Test title/setup flow, cell interaction, cascade animation, theme toggle, fullscreen controls, responsive layout and reduced-motion preference.

For a compatibility issue, record browser version, OS, viewport, reproduction steps, console errors and gameplay impact. Node support for the build toolchain is distinct from browser support.
