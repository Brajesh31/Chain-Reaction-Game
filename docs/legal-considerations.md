# 📑 Legal and Distribution Considerations

The root LICENSE is explicitly limited to documentation and repository guidance authored for this maintenance contribution. It does not establish redistribution rights for all pre-existing application source, branding or third-party assets. Review source history and provenance before redistributing the entire project.

Review package licenses and preserve upstream notices. Record reused external assets in ASSET_ATTRIBUTION.md.

The current product has no accounts, chat, user uploads or remote analytics service in the checked-in app. Reassess when these capabilities are introduced. This page is an engineering checklist, not legal advice.
