# 💥 Branding Guidelines

Use the project name **Chain Reaction Game**. The public logo and icons live under public/. The visual language uses a dark/light interface, cyan accents and red/blue/green/yellow player orbs.

## Visual direction
- Cyan is the main interface accent.
- Use player colors consistently across board, labels and status.
- Keep strong contrast between cells and page surfaces.
- Use orb/grid imagery connected to the gameplay.
- Keep titles legible at README width.

Use repository-owned SVGs or verified screenshots from a running build. Provide alt text. Do not label concept art as a runtime capture. Record external asset attribution in ASSET_ATTRIBUTION.md.
