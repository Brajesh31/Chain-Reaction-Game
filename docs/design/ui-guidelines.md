# 🎨 UI and Interaction Guidelines

## Visual hierarchy
- Make the active player's turn obvious.
- Keep cells distinct from the page background.
- Separate reset/settings controls from board interaction.
- Explain objective and critical-mass rules before play.

## Feedback
- Give rejected moves clear non-color-only feedback.
- Make explosions understandable without delaying rule resolution.
- Announce victory distinctly.
- Make reset behavior predictable.

## Responsive layout
- Preserve square cells where practical.
- Keep controls reachable on narrow screens.
- Avoid horizontal overflow.
- Verify browser zoom and text scaling.

## Consistency
Use the same player identity, color and label across board, turn display and status feedback.
