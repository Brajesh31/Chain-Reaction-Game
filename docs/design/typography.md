# 🔤 Typography

The global stylesheet uses a system sans-serif stack (system UI, Segoe UI, Roboto and platform fallbacks). Code elements use a monospace stack. The title screen applies local font sizing, weight and letter spacing.

## Guidance
- Prefer the system stack to avoid remote font dependencies.
- Reserve large, heavy text for the title and important status.
- Keep instructions and cell labels readable at mobile widths.
- Do not use typography as the only signal of ownership or turn state.
- Preserve browser zoom and text scaling.

Review both themes, narrow viewports and 200% zoom when changing typography.
