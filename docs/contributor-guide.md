# 🤝 Contributor Guide

1. Read README, product scope and the relevant docs.
2. Search existing issues and pull requests.
3. Reproduce the issue with exact steps or a board fixture.
4. Create a focused branch from main.
5. Make a minimal change addressing the problem.
6. Add deterministic unit/component tests for changed behavior.
7. Run tests, build and repository validation.
8. Update docs, diagrams and changelog.
9. Open a pull request with evidence and known limitations.

For rule changes, specify corner/edge/interior thresholds, orthogonal propagation, ownership conversion, participation/elimination and winner behavior. Do not report tests that were not run or claim online features from dependencies.
