# 🍪 Cookie and Browser Storage Status

The checked-in application does not implement an application login cookie or server session. It does not intentionally persist match state in localStorage or IndexedDB.

The hosting provider, CDN or browser tooling may use infrastructure cookies or logs outside this repository. Verify deployed behavior before claiming that the entire service uses no cookies or tracking.

If analytics, authentication or persistent storage is introduced, document storage keys, purpose, expiry, user controls and applicable consent requirements.
