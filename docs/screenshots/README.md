# 📷 Screenshot Capture Guide

The repository contains authored SVG diagrams for conceptual visuals. No live runtime screenshot is represented as captured evidence.

## Capture checklist
1. Run npm ci and npm start.
2. Capture title screen at desktop and mobile widths.
3. Capture setup and player/grid choices.
4. Capture mid-game board and active-player indicator.
5. Capture a cascade and settled board.
6. Capture light and dark themes.
7. Remove browser personal data and local filesystem paths.
8. Use consistent viewports; do not edit game results into an image.

Suggested names: title-desktop.png, setup-mobile.png, game-dark-desktop.png, cascade-desktop.png and game-light-mobile.png.

Store screenshots here only after capture from the verified app. Add alt text and link them from the relevant guide. Never substitute an illustration for runtime evidence.
