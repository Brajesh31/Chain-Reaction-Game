# 🔐 Privacy Overview

The checked-in game is a local browser experience. No account service, database, online matchmaking, analytics backend or remote match storage is implemented. Board and turn state remain in React memory for the current session.

This is a technical description, not legal advice or a guarantee about the hosting provider, browser extensions or the user's device. Verify deployed network behavior and provider logs before publishing a full privacy statement.

See root PRIVACY.md, [data handling](security/data-handling.md), [retention](data-retention.md) and [deletion](data-deletion.md).
