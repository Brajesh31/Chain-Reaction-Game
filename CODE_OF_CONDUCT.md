# Code of Conduct

This project welcomes contributors with different skills, backgrounds, and perspectives. Everyone participating in project spaces should help make them respectful and constructive.

## Expected behavior

- Treat people with courtesy and patience.
- Critique code and ideas without insulting or targeting contributors.
- Assume good faith where reasonable and explain disagreement with useful context.
- Respect privacy and never publish credentials or personal information.
- Make room for people to learn and ask questions.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, repeated unwanted contact, doxxing, deliberate disruption, sexualized attention without consent, and retaliation for raising a concern are not acceptable in project spaces.

## Maintainer response

Maintainers may edit or remove harmful content, pause a discussion, or restrict participation when needed to protect contributors and keep the project usable. Responses should be proportionate and may range from a warning to temporary or permanent exclusion.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the `@brajesh31` GitHub profile. Include enough context to understand the issue and avoid sending sensitive information unnecessarily. For security vulnerabilities, use [SECURITY.md](SECURITY.md) instead of a public issue. If the concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository issues, discussions, pull requests, and other spaces where someone is participating on behalf of the project.
