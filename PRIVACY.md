# 🔒 Privacy

## Current scope
The current game is designed for local hot-seat play. Match state is held in browser memory. No account service, database, online match API or analytics backend was identified in the checked-in implementation.

## Rules
- Do not commit credentials or personal data.
- Do not collect player names, contact details or analytics without a documented product need.
- Keep public frontend environment variables free of secrets.
- Document any future local storage, cookies or network transmissions accurately.
- For a future online mode, document data purpose, retention, deletion, processors and access controls before launch.

This file describes project intent and is not a legal compliance certification.
