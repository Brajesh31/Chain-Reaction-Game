# Support

This is a community project and does not provide a support service or response-time guarantee.

## Questions and bug reports

Search existing [issues](https://github.com/Brajesh31/Chain-Reaction-Game/issues) first, then open an issue with the browser, operating system, grid size, player count, expected behavior, and what happened. For a visual issue, add a screenshot or a short clip if it contains no private information.

For gameplay bugs, include the moves that led to the issue. For setup problems, include Node.js/npm versions and the command that failed, with local paths, usernames, and environment values removed.

## Security reports

Do not post a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) and use a private reporting channel.

## Scope

There is no hosted multiplayer service, database support, or deployment support in the current repository. See [CONTRIBUTING.md](CONTRIBUTING.md) to propose a fix or documentation update.
