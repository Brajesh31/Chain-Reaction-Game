# 🎨 Asset Attribution

Keep a record for every non-original asset added to the project.

| Asset path | Creator | Source/license | Required attribution | Notes |
|---|---|---|---|---|
| `public/logo.svg` | Project repository | Review asset history | Verify before redistribution | Existing project asset |

## Rules
- Do not assume an asset is reusable because it is publicly visible.
- Record source and license before adding external images, fonts, sounds or icons.
- Preserve required notices and license files.
- Prefer original SVG/CSS visuals for diagrams where practical.
- Review attribution during release preparation.

Update this table when assets change. This inventory is not a substitute for checking each license.
