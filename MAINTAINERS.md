# 🧑‍💻 Maintainers

The repository owner manages project direction, releases, access and security response.

## Review responsibilities
- Review changes to game rules and endgame behavior.
- Require tests and documentation for behavior changes.
- Review dependency and workflow modifications.
- Keep repository metadata aligned with shipped code.

Use GitHub issues for ordinary defects and private vulnerability reporting for security-sensitive findings. Never post secrets or private data publicly.
